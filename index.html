💡 Golden Rule

You are the PM. AI is your intern. The more specific your instructions, the better the output. Always end with: "Use mock data for now. No backend needed." — get the UI working first, worry about data later.

🏗️

Starting From Scratch

Build a Full App 
Build a [web/mobile app] called [name].

Core purpose: [one sentence describing what it does]

Main pages:
1. [Page Name] — [what it shows or does]
2. [Page Name] — [what it shows or does]
3. [Page Name] — [what it shows or does]

Key features:
- [feature 1]
- [feature 2]
- [feature 3]

Target user: [who is this for]

Design vibe: Clean and modern. [any extra style notes]

Use mock data for now. No backend needed.
Landing Page Only 
Build a landing page for [app name].

It should have:
- A hero section with headline: "[your tagline]"
- A features section with 3 key benefits
- A call-to-action button that says "[button text]"

Target user: [who is this for]

Design vibe: Clean and modern. [any extra style notes]
Dashboard Only 
Build a dashboard page for [app name].

The dashboard should show:
- [metric/card 1] (e.g. total users, balance, items)
- [metric/card 2]
- [metric/card 3]
- A [table/list/chart] showing [what data]

Use mock data. Clean modern UI.
🔧

Iterate & Modify

Change the Design Style 
Keep all the functionality exactly the same.
Only change the design to look more [modern / minimal / bold / friendly / professional].
Use [color palette if you have one].
Do not touch any logic or structure.
Add a New Page 
Add a new page called [page name].
It should [describe what it does].
Add a link to this page in the navigation bar.
Keep everything else exactly the same.
Change Colors / Fonts / Layout 
Update the visual design only. Do not change any functionality.
- Change primary color to [color]
- Change font to [font name or style]
- [Any layout changes, e.g. "move the sidebar to the left"]
Replace Mock Data with Real Content 
Replace all the placeholder/mock data with this real content:
[paste your real content here]

Keep the design and layout exactly the same.
🐛

When Things Break

AI Changed the Wrong Things 
You changed things I didn't ask you to change.
Please revert everything back to how it was before,
and only make this specific change:
[describe the one thing you actually wanted]

Tip: Be very specific about what the one change is.

Page is Broken / Looks Wrong 
Something broke after your last edit.
The page is now showing [describe the error or what looks wrong].
Please fix this without changing anything else.
Feature Not Working Correctly 
The [feature name] is not working correctly.
When I [describe what you do], it should [describe expected behavior],
but instead it [describe what actually happens].
Please fix only this issue.
➕

Add Features

Add a Search Bar 
Add a search bar to the [page name] page.
It should filter the [list/table] in real time as the user types.
Search should match against [field name, e.g. title, name, category].
Do not change anything else.
Add Login / Signup 
Add a simple login and signup page.
- Login page: email + password fields + login button
- Signup page: name + email + password + confirm password + signup button

Use mock authentication for now (no real backend).
After "logging in", redirect to [page name].
Add a Form 
Add a form to [page name] that collects:
- [field 1] (type: text/email/dropdown/etc)
- [field 2]
- [field 3]

On submit, show a success message that says "[your success message]".
Use mock submission for now, no backend needed.
Add Google Maps / Location 
Add a map to [page name] using Google Maps or Mapbox.
The map should show [what it displays, e.g. a pin at a specific location / multiple locations from a list].
Use this API key: [your key]
Keep everything else the same.
Add an AI Chat Widget 
Add an AI chat widget to the bottom right corner of the app.
It should:
- Open when clicked
- Let users type questions
- Respond with helpful answers about [your app's topic]

Use the Anthropic Claude API with this key: [your key]
System prompt: "You are a helpful assistant for [app name]. You help users with [what your app does]."
📱

Platform & Polish

Make It Mobile-Friendly 
Make the entire app fully responsive for mobile screens.
- Navigation should collapse into a hamburger menu on small screens
- All cards and tables should stack vertically on mobile
- Text and buttons should be readable without zooming
Do not change the desktop layout.
Add Dark Mode 
Add a dark mode toggle to the navigation bar.
When dark mode is on, switch to a dark background with light text.
Remember the user's preference.
Do not change any functionality.
🚀

Get Demo-Ready

Make Mock Data More Realistic 
Replace all placeholder data with realistic, believable fake data that fits our app.
For [app name], the data should look like [describe your real use case].
Make it feel like a real product, not a template.
Add Animations to Look More Polished 
Add subtle animations to make the app feel more polished:
- Smooth page transitions
- Cards fade in when the page loads
- Buttons have a hover effect

Keep animations minimal and professional.
Do not change any functionality or layout.
